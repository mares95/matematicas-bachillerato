# Guía de actividades — Unidad 5: Creatividad con tecnología para diseñar soluciones

**Tecnología · Año 1 · Semestre 2**

## Parte A — Opción múltiple / Verdadero y Falso

1. Ordena las 5 fases del design thinking: Prototipar, Empatizar, Evaluar, Definir, Idear.
2. El proceso de design thinking es estrictamente lineal: nunca se regresa a una fase anterior. **(V / F)**
3. Un sensor de humedad es un ejemplo de: **(a) actuador / (b) sensor)**.
4. Un motor que hace girar una rueda es un ejemplo de: **(a) actuador / (b) sensor)**.
5. Si un prototipo falla en las pruebas, lo correcto es: **(a) abandonar la idea por completo / (b) documentar la falla y ajustar el diseño)**.

## Parte B — Caso práctico (respuesta breve)

6. Identifica un problema real en tu escuela o comunidad (ej. desperdicio de agua, falta de señalización, manejo de basura). Redacta un enunciado de problema (fase "Definir") en una sola oración clara.
7. Para el problema anterior, propón al menos 3 ideas distintas de solución (fase "Idear"), sin evaluarlas todavía.

## Parte C — Mini-proyecto: prototipo con design thinking

8. En equipos, apliquen las 5 fases del design thinking a un problema real de su entorno y construyan un prototipo simple (puede ser de materiales reciclados, cartón, o un diagrama detallado si no es posible construirlo físicamente). Documenten cada fase.

**Lista de cotejo para el mini-proyecto (Parte C):**

| Criterio | Cumple |
|---|---|
| Se documentan las 5 fases del proceso | ☐ |
| El problema definido es claro y específico | ☐ |
| El prototipo (o su diagrama) es coherente con la solución idead | ☐ |
| Se realizaron al menos una prueba y un ajuste (iteración) | ☐ |
| Se consideró el costo y/o el impacto ambiental de los materiales | ☐ |

---

## Clave de respuestas

1. **Empatizar → Definir → Idear → Prototipar → Evaluar**
2. **F** — es un proceso iterativo, se puede regresar a fases anteriores
3. **(b)** sensor (recibe información del entorno)
4. **(a)** actuador (produce una acción)
5. **(b)** documentar la falla y ajustar el diseño (iterar)
6. Respuesta abierta — se evalúa que sea una oración clara y específica, no vaga.
7. Respuesta abierta — se evalúa variedad y creatividad de las 3 ideas.
8. Se evalúa con la lista de cotejo.
